# Generated data

Run `./reproduce.sh` from `experiments/` for the complete evidence chain, or
`.venv/bin/python -m sim.generate --seed 0` there for just the journey data.
`events.parquet` and `truth.json` are ignored by Git. Compact test and validation
evidence is versioned in `../results/` and regenerated by that same command.
All journeys are simulated, inspired by embedded-lending partner funnels.
Arrivals span days 0–139; repeat outcomes include full follow-up through day 229.
